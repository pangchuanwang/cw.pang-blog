# 009｜找到字符串中所有字母异位词

**LeetCode：** 438　**标签：** `滑动窗口` `字母计数`　**难度：** 中等

给定仅包含小写字母的字符串 `s` 和 `p`，返回 `s` 中所有与 `p` 互为字母异位词的子串起始下标。

- `s = "cbaebabacd"`，`p = "abc"` → `[0,6]`。
- `s = "abab"`，`p = "ab"` → `[0,1,2]`，窗口可以重叠。

## 共同思路：固定长度的滑动窗口

字母异位词的长度和各字母出现次数都相同，顺序可以不同。因此窗口长度固定为 `p.size()`，只需判断窗口与 `p` 的字母计数是否相同。

每次窗口右移一格，移除最左边的字符，加入右边的新字符，不必重新统计整个窗口。`s` 比 `p` 短时，直接返回空答案。

## 方法一：比较两个计数数组

用长度为 26 的数组分别记录当前窗口和 `p` 的字母计数。`c - 'a'` 将字母映射到 `0～25`。两个数组相等，就说明每个字母的数量都相同。

```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        int n = s.size();
        int m = p.size();

        // 无法构造长度为 m 的窗口。
        if (n < m) {
            return {};
        }

        vector<int> ans;

        // 26 个计数初始均为 0，分别对应 a 到 z。
        vector<int> windowCount(26);
        vector<int> targetCount(26);

        // 统计第一个窗口 s[0..m-1] 和目标字符串 p。
        for (int i = 0; i < m; ++i) {
            ++windowCount[s[i] - 'a'];
            ++targetCount[p[i] - 'a'];
        }

        // 单独检查第一个窗口，其起始下标为 0。
        if (windowCount == targetCount) {
            ans.push_back(0);
        }

        // left 是移动前窗口的起始下标。
        for (int left = 0; left < n - m; ++left) {
            // 移除离开窗口的最左字符。
            --windowCount[s[left] - 'a'];

            // 加入新窗口最右边的字符。
            ++windowCount[s[left + m] - 'a'];

            // 移动后的窗口起点是 left + 1。
            if (windowCount == targetCount) {
                ans.push_back(left + 1);
            }
        }

        return ans;
    }
};
```

**下标理解：** 旧窗口是 `[left, left + m - 1]`，新窗口是 `[left + 1, left + m]`。因此移除 `s[left]`，加入 `s[left + m]`，记录的新起点为 `left + 1`。

以 `s = "abab"`、`p = "ab"` 为例：

| 窗口 | 移除 | 加入 | 当前子串 | 起始下标 |
|---|---|---|---|---:|
| 初始 | — | — | ab | 0 |
| 右移一格 | a | a | ba | 1 |
| 再右移一格 | b | b | ab | 2 |

三个窗口的字母计数都与 `p` 相同，答案为 `[0,1,2]`。

**复杂度：** 每次比较最多检查 26 项，时间为 `O(m + 26(n - m + 1))`；26 是常数，可记为 `O(n + m)`。不计答案，额外空间为 `O(26)`，即 `O(1)`。

## 方法二：维护计数差和 diff

方法一每次比较整个计数数组。方法二保存差值，并维护有多少种字母的计数不一致，只需检查 `diff == 0`。

```text
count[c] = 当前窗口中 c 的数量 - p 中 c 的数量
diff = count 数组中非零项的数量
```

例如窗口 `"aab"`、目标 `"abc"`，有 `a: +1`、`b: 0`、`c: -1`，因此 `diff = 2`。它表示两种字母的数量不一致，并不是差值之和。

### diff 为什么这样更新？

只关心计数差是否跨过 0：

| 操作 | 更新前的差值 | 更新后的差值 | diff 变化 |
|---|---:|---:|---|
| 移除字符，差值减 1 | 1 | 0 | 减 1，变为一致 |
| 移除字符，差值减 1 | 0 | -1 | 加 1，变为不一致 |
| 加入字符，差值加 1 | -1 | 0 | 减 1，变为一致 |
| 加入字符，差值加 1 | 0 | 1 | 加 1，变为不一致 |

其他变化，如 `2 → 1` 或 `-2 → -1`，更新前后都非零，因此 `diff` 不变。下面代码先判断旧差值，再修改差值。

```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        int n = s.size();
        int m = p.size();
        if (n < m) {
            return {};
        }

        vector<int> ans;

        // 记录当前窗口计数减去目标计数的差值。
        vector<int> count(26);
        for (int i = 0; i < m; ++i) {
            ++count[s[i] - 'a'];
            --count[p[i] - 'a'];
        }

        // 统计有多少种字母的计数不一致。
        int diff = 0;
        for (int value : count) {
            if (value != 0) {
                ++diff;
            }
        }

        if (diff == 0) {
            ans.push_back(0);
        }

        for (int left = 0; left < n - m; ++left) {
            int outgoing = s[left] - 'a';

            // 移除字符前，根据差值是否跨过 0 更新 diff。
            if (count[outgoing] == 1) {
                --diff;
            } else if (count[outgoing] == 0) {
                ++diff;
            }
            --count[outgoing];

            int incoming = s[left + m] - 'a';

            // 加入字符前，根据差值是否跨过 0 更新 diff。
            if (count[incoming] == -1) {
                --diff;
            } else if (count[incoming] == 0) {
                ++diff;
            }
            ++count[incoming];

            // 先完成移除和加入，再判断整个新窗口。
            if (diff == 0) {
                ans.push_back(left + 1);
            }
        }

        return ans;
    }
};
```

移除与加入可能是同一个字母，例如 `"abab"` 中从 `"ab"` 滑到 `"ba"`：移除 a 后暂时不匹配，加入 a 后恢复匹配。因此必须完成两步之后再检查 `diff`。

**复杂度：** 时间 `O(n + m + 26)`，即 `O(n + m)`；不计答案，额外空间 `O(26)`，即 `O(1)`。它减少了每次窗口移动后的比较操作，两种方法的渐进复杂度相同。

**复习重点：** 先掌握方法一的固定长度窗口与下标更新，再理解方法二只维护“计数差从零变非零、从非零变零”的变化。
