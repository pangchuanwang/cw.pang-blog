# 002｜字母异位词分组

**标签：** `Hash`　**难度：** 中等

把由相同字母组成的字符串分到一组。题目字符串只包含小写字母。

## 解法一：排序后作为键

字母异位词排序后相同，用排序结果作为哈希表的键，原字符串放入对应列表。

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        // 排序后的字符串作为键，值保存对应的原字符串。
        unordered_map<string, vector<string>> groups;

        // 逐个处理输入字符串。
        for (const string& s : strs) {
            // 复制字符串作为分组键，不改动原字符串。
            string key = s;

            // 字母异位词排序后会得到相同的键。
            sort(key.begin(), key.end());

            // 将原字符串加入对应分组。
            groups[key].push_back(s);
        }

        // 收集哈希表中的所有分组。
        vector<vector<string>> ans;
        for (auto& [key, group] : groups) {
            ans.push_back(group);
        }

        // 返回分组结果；分组顺序不固定。
        return ans;
    }
};
```

设字符串数量为 `n`，平均长度为 `k`：时间 `O(n · k log k)`，空间 `O(nk)`。

## 解法二：字母计数作为键

字母异位词中每个字母的出现次数都相同。用长度为 26 的数组统计字符频次，作为哈希表的键。

```cpp
class Solution {
    // 为计数数组提供哈希函数，使其可用作 unordered_map 的键。
    struct ArrayHash {
        size_t operator()(const array<int, 26>& counts) const {
            size_t seed = 0;

            // 依次合并 26 个字母的出现次数。
            for (int count : counts) {
                seed = seed * 31 + hash<int>{}(count);
            }

            // 返回计数数组对应的哈希值。
            return seed;
        }
    };

public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        // 字母频次数组作为键，值保存对应的字符串分组。
        unordered_map<array<int, 26>, vector<string>, ArrayHash> groups;

        // 逐个处理输入字符串。
        for (const string& s : strs) {
            // 建立 26 个小写字母的计数表，初始值均为 0。
            array<int, 26> counts{};

            // 遍历字符串中的字符并统计出现次数。
            for (char c : s) {
                // 将 'a' 到 'z' 映射到下标 0 到 25。
                ++counts[c - 'a'];
            }

            // 频次相同的字符串会进入同一个分组。
            groups[counts].push_back(s);
        }

        // 收集哈希表中的所有分组。
        vector<vector<string>> ans;
        for (auto& [key, group] : groups) {
            ans.push_back(group);
        }

        // 返回分组结果；分组顺序不固定。
        return ans;
    }
};
```

设字符串数量为 `n`，平均长度为 `k`：时间 `O(nk)`，空间 `O(nk)`。每个字符串只遍历一次，计数数组长度固定为 26。
