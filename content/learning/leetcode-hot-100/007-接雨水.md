# 007｜接雨水

**LeetCode：** 42　**标签：** `动态规划` `单调栈` `双指针`　**难度：** 困难

给定非负整数数组 `height`，每个数字代表一根宽度为 1 的柱子的高度，求这些柱子之间能接住多少雨水。

- `[0,1,0,2,1,0,1,3,2,1,2,1]` → `6`
- `[4,2,0,3,2,5]` → `9`

**学习重点：** 先用方法一理解每个位置如何计算水量，再用方法三掌握空间优化。方法二需要理解栈如何按层计算水量。

## 先理解：一个位置能接多少水？

位置 `i` 上方能接的水，同时受左右两边最高柱子的限制。水位只能达到两侧最高柱子中较矮的一侧，否则会从那边流走。

```text
水位 = min(左侧最高柱子, 右侧最高柱子)
当前位置水量 = 水位 - 当前柱高
```

左右最高高度都包含当前位置，因此水量不会是负数；每根柱子宽度为 1，不需要再乘宽度。

以 `[4,2,0,3,2,5]` 为例，中间四个位置的水位都是 4，水量分别是 `2、4、1、2`，总量为 `9`。

## 方法一：动态规划（重点掌握）

### 1. 保存什么信息？

用两个数组提前记录每个位置左右两侧的最高高度：

- `leftMax[i]`：区间 `[0, i]` 的最高柱子。
- `rightMax[i]`：区间 `[i, n - 1]` 的最高柱子。

如果每算一个位置都重新向左右扫描，会花 `O(n²)` 时间。现在把最高高度提前算好，每个位置就能直接查数组。

### 2. 为什么能递推？

从左到右看，前一个位置已经知道了左侧最高高度。加入当前柱子后，只需比较二者：

```text
leftMax[0] = height[0]
leftMax[i] = max(leftMax[i - 1], height[i])
```

从右到左同理，但要使用已经算好的 `rightMax[i + 1]`：

```text
rightMax[n - 1] = height[n - 1]
rightMax[i] = max(rightMax[i + 1], height[i])
```

最后逐个位置计算 `min(leftMax[i], rightMax[i]) - height[i]` 并累加。

### 3. 手算过程

| 下标 i | 柱高 | leftMax[i] | rightMax[i] | 水位 | 水量 |
|---|---:|---:|---:|---:|---:|
| 0 | 4 | 4 | 5 | 4 | 0 |
| 1 | 2 | 4 | 5 | 4 | 2 |
| 2 | 0 | 4 | 5 | 4 | 4 |
| 3 | 3 | 4 | 5 | 4 | 1 |
| 4 | 2 | 4 | 5 | 4 | 2 |
| 5 | 5 | 5 | 5 | 5 | 0 |

总水量：`0 + 2 + 4 + 1 + 2 + 0 = 9`。

### 4. C++ 代码

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = height.size();

        // 少于三根柱子，无法形成蓄水区域。
        if (n < 3) {
            return 0;
        }

        // 保存每个位置左侧和右侧的最高柱高。
        vector<int> leftMax(n);
        vector<int> rightMax(n);

        // 左端点的左侧最高高度就是它自身。
        leftMax[0] = height[0];
        for (int i = 1; i < n; ++i) {
            // 比较前面已知的最高柱子与当前柱子。
            leftMax[i] = max(leftMax[i - 1], height[i]);
        }

        // 右端点的右侧最高高度就是它自身。
        rightMax[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; --i) {
            // 反向遍历，使用已计算的右侧最高高度。
            rightMax[i] = max(rightMax[i + 1], height[i]);
        }

        int water = 0;
        for (int i = 0; i < n; ++i) {
            // 水位由两侧最高柱子中较矮的一侧决定。
            int level = min(leftMax[i], rightMax[i]);

            // 减去柱子本身的高度，得到该位置的水量。
            water += level - height[i];
        }

        return water;
    }
};
```

**复杂度：** 时间 `O(n)`，额外空间 `O(n)`。虽然有三次遍历，但 `3n` 仍然是线性规模。

**记忆顺序：** 正向算左边最高 → 反向算右边最高 → 取较小高度减柱高。

## 方法二：单调栈

### 1. 栈里保存什么？

保存柱子的**下标**，从栈底到栈顶对应的高度保持非递增，相同高度可以共存。保存下标是为了计算柱子之间的距离。

当当前柱子比栈顶高时，说明右侧出现了可以挡水的柱子。弹出的栈顶作为凹槽底部，新的栈顶作为左边界，当前柱子作为右边界。

```text
左边界：弹出底部后，新的栈顶 left
凹槽底：弹出的下标 bottom
右边界：当前下标 right

宽度 = right - left - 1
新增水层高度 = min(height[left], height[right]) - height[bottom]
新增水量 = 宽度 × 新增水层高度
```

宽度减 1，是因为左右边界柱子本身不占蓄水宽度。若弹出底部后栈为空，就没有左边界，不能计算水量。

### 2. 为什么会连续弹栈？

当前柱子可能比多个较低的柱子都高，因此能填出多层水。每弹出一次，计算一层新增加的水，再检查更高的底部。

以 `[3,0,1,3]` 为例：

1. 扫描到下标 2（高度 1），弹出下标 1（高度 0）。左边界是下标 0，宽度 1，新增高度 1，得到 `1` 单位水。
2. 扫描到下标 3（高度 3），弹出下标 2（高度 1）。左边界仍是下标 0，宽度 2，新增高度 `3 - 1 = 2`，得到 `4` 单位水。
3. 总水量 `1 + 4 = 5`。第二次只算高度 1 以上的新水层，因此没有重复计算。

### 3. C++ 代码

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int water = 0;

        // 存下标；对应柱高从栈底到栈顶非递增。
        stack<int> indices;
        int n = height.size();

        for (int right = 0; right < n; ++right) {
            // 当前柱子更高，尝试为栈顶凹槽计算水量。
            while (!indices.empty()
                   && height[right] > height[indices.top()]) {
                // 弹出的柱子作为本次计算的凹槽底部。
                int bottom = indices.top();
                indices.pop();

                // 没有左边界，无法形成蓄水区域。
                if (indices.empty()) {
                    break;
                }

                // 新栈顶是左边界，当前柱子是右边界。
                int left = indices.top();

                // 只计算两根边界柱子之间的宽度。
                int width = right - left - 1;

                // 两侧较矮高度减去底部，得到新增水层高度。
                int level = min(height[left], height[right]);
                int layerHeight = level - height[bottom];

                water += width * layerHeight;
            }

            // 当前柱子留作后续凹槽的底部或左边界。
            indices.push(right);
        }

        return water;
    }
};
```

**复杂度：** 时间 `O(n)`，额外空间 `O(n)`。即使有内层 `while`，每个下标也只会入栈一次、出栈至多一次，总操作次数仍为线性。

**理解重点：** 动态规划按“每一列”计算水；单调栈按“每一层矩形区域”计算水。

## 方法三：双指针（重点掌握）

### 1. 从方法一怎么优化？

方法一保存了所有位置的左右最高高度。但如果只处理当前能确定水量的位置，就不必保留两个完整数组。

用两个指针夹住尚未处理的区间，并维护两个变量：

- `leftMax`：区间 `[0, left]` 中已经看到的最高柱子。
- `rightMax`：区间 `[right, n - 1]` 中已经看到的最高柱子。

每轮先用当前柱高更新两个最大值，再处理最大值较小的一侧。

### 2. 为什么不用知道另一侧的完整最高高度？

若 `leftMax <= rightMax`，就可以直接算 `left` 位置的水量：

```text
左侧的最高高度 = leftMax，已经确定。
右侧的完整最高高度 >= rightMax >= leftMax。
所以两侧取最小值，一定得到 leftMax。
当前水量 = leftMax - height[left]。
```

右侧尚未扫描的区间即使有更高柱子，也不会改变这个最小值，因此可以放心计算并让 `left` 右移。

若 `leftMax > rightMax`，对称地计算 `rightMax - height[right]`，然后让 `right` 左移。

**这里的比较对象是已知最高高度，而不是只看当前柱高。** 截图使用比较当前柱高的双指针写法；下面采用比较 `leftMax`、`rightMax` 的版本，更容易直接对应方法一的公式。循环使用 `left <= right`，把最后一个位置也统一处理。

### 3. 手算过程

对 `[4,2,0,3,2,5]`，右端最高高度一直是 5。左侧已知最高高度起初为 4，因此不断处理左侧：

| 处理下标 | 柱高 | leftMax | rightMax | 本次水量 | 累计水量 |
|---|---:|---:|---:|---:|---:|
| 0 | 4 | 4 | 5 | 0 | 0 |
| 1 | 2 | 4 | 5 | 2 | 2 |
| 2 | 0 | 4 | 5 | 4 | 6 |
| 3 | 3 | 4 | 5 | 1 | 7 |
| 4 | 2 | 4 | 5 | 2 | 9 |
| 5 | 5 | 5 | 5 | 0 | 9 |

右侧处理的例子：`[5,0,2]`。左侧最高为 5，右侧最高为 2，所以先处理右端，再处理高度为 0 的位置，得到 `2 - 0 = 2` 单位水。

### 4. C++ 代码

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = height.size();
        if (n < 3) {
            return 0;
        }

        // 两指针夹住尚未计算水量的区间。
        int left = 0;
        int right = n - 1;

        // 保存从两端扫描到的最高柱高。
        int leftMax = 0;
        int rightMax = 0;
        int water = 0;

        while (left <= right) {
            // 先把当前两根柱子纳入各自的最高高度。
            leftMax = max(leftMax, height[left]);
            rightMax = max(rightMax, height[right]);

            if (leftMax <= rightMax) {
                // 右侧已有足够高的柱子，左侧水位确定为 leftMax。
                water += leftMax - height[left];

                // 左侧这个位置已算完，继续向右扫描。
                ++left;
            } else {
                // 左侧已有足够高的柱子，右侧水位确定为 rightMax。
                water += rightMax - height[right];

                // 右侧这个位置已算完，继续向左扫描。
                --right;
            }
        }

        return water;
    }
};
```

**复杂度：** 时间 `O(n)`，额外空间 `O(1)`。每个位置只处理一次，只保存指针和两侧最高高度。

**记忆顺序：** 更新两侧最高高度 → 计算最高高度较小的一侧 → 移动该侧指针。

## 复习对照

| 方法 | 计算方式 | 时间 | 额外空间 | 掌握重点 |
|---|---|---|---|---|
| 动态规划 | 保存左右最高高度，逐列计算 | O(n) | O(n) | 先理解水位公式和递推 |
| 单调栈 | 找左右边界，逐层计算 | O(n) | O(n) | 栈存下标、弹栈形成水层 |
| 双指针 | 两侧向中间扫描，逐列计算 | O(n) | O(1) | 为什么较小的最高高度能确定水位 |

注意：接雨水要求把各位置的水量**相加**；「盛最多水的容器」只选择两条线，求一个容器的**最大面积**。这里减去柱高，是因为柱子本身占据了空间。
