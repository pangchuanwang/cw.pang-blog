# 006｜三数之和

**标签：** `双指针` `排序`　**难度：** 中等

给定整数数组 `nums`，返回所有和为 `0` 的三元组。三个元素的下标必须不同，答案不能包含重复三元组。

示例：`[-1,0,1,2,-1,-4]` → `[[-1,-1,2],[-1,0,1]]`

## 解法：排序 + 双指针

排序后固定第一个数，用左右指针寻找另外两个数。三数之和太小时移动左指针，太大时移动右指针；找到答案后跳过重复值。

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        // 排序后，才能根据和的大小移动左右指针。
        sort(nums.begin(), nums.end());

        // 保存找到的三元组。
        vector<vector<int>> ans;
        int n = nums.size();

        // 固定第一个数，后面至少留出两个位置。
        for (int i = 0; i + 2 < n; ++i) {
            // 当前数已大于 0，后面的数更大，不可能凑成 0。
            if (nums[i] > 0) {
                break;
            }

            // 跳过重复的第一个数，避免生成重复三元组。
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            // 在第一个数后面的区间中寻找另外两个数。
            int left = i + 1;
            int right = n - 1;

            while (left < right) {
                // 直接计算三数之和，便于理解判断条件。
                int sum = nums[i] + nums[left] + nums[right];

                if (sum < 0) {
                    // 和太小，左指针右移，尝试更大的数。
                    ++left;
                } else if (sum > 0) {
                    // 和太大，右指针左移，尝试更小的数。
                    --right;
                } else {
                    // 找到一个满足条件的三元组。
                    ans.push_back({nums[i], nums[left], nums[right]});

                    // 当前组合已记录，继续向内寻找其他组合。
                    ++left;
                    --right;

                    // 跳过与刚才使用的数相同的值，避免重复答案。
                    while (left < right && nums[left] == nums[left - 1]) {
                        ++left;
                    }
                    while (left < right && nums[right] == nums[right + 1]) {
                        --right;
                    }
                }
            }
        }

        // 返回所有不重复的三元组。
        return ans;
    }
};
```

**去重关键：** 外层跳过重复的第一个数；找到答案后，左右指针也跳过刚用过的重复值。下标始终满足 `i < left < right`，因此不会重复使用同一元素。

**复杂度：** 时间 `O(n²)`；不计返回结果，排序通常需要 `O(log n)` 的额外栈空间。排序会改变输入数组的顺序。
