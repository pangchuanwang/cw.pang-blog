# 004｜移动零

**标签：** `双指针`　**难度：** 简单

将数组中的所有 `0` 移到末尾，同时保持非零元素的相对顺序，并原地修改数组。

示例：`[0,1,0,3,12]` → `[1,3,12,0,0]`

## 解法：双指针

`right` 负责遍历数组，`left` 指向下一个非零数应该放置的位置。遇到非零数，就与 `left` 位置交换，然后让 `left` 前进。

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        // left 指向下一个非零数的放置位置。
        int left = 0;

        // right 从左到右扫描数组。
        for (int right = 0; right < nums.size(); ++right) {
            // 只处理非零数；扫描顺序保证非零数的相对顺序不变。
            if (nums[right] != 0) {
                // 将当前非零数放到 left 指向的位置。
                swap(nums[left], nums[right]);

                // 下一个非零数应放在后一格。
                ++left;
            }
        }
    }
};
```

以 `[0,1,0,3,12]` 为例：扫描到 `1` 时，将它换到下标 `0`；扫描到 `3` 时，将它换到下标 `1`；扫描到 `12` 时，将它换到下标 `2`。最终得到 `[1,3,12,0,0]`。

**复杂度：** 时间 `O(n)`，额外空间 `O(1)`。每个元素扫描一次，交换直接在原数组中完成。
