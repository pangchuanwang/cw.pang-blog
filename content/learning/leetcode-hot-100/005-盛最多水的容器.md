# 005｜盛最多水的容器

**标签：** `双指针`　**难度：** 中等

给定数组 `height`，第 `i` 条竖线的高度为 `height[i]`。选择两条线，与 x 轴围成容器，求容器能装水的最大面积。

示例：`height = [1,8,6,2,5,4,8,3,7]` → `49`。

## 解法：双指针

两条线围成的面积由较短的线决定：`面积 = 较短线高度 × 两线间距`。从数组两端开始，每次移动较短线的指针，尝试找到更高的线。

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        // 左右指针从数组两端开始。
        int left = 0;
        int right = height.size() - 1;

        // 保存目前发现的最大面积。
        int maxWater = 0;

        // 两指针相遇后，不再能围成容器。
        while (left < right) {
            // 容器高度由较短的线决定，宽度是两线间距。
            int width = right - left;
            int water = min(height[left], height[right]) * width;

            // 更新最大面积。
            maxWater = max(maxWater, water);

            // 移动较短的一侧，才有机会找到更高的边界。
            if (height[left] <= height[right]) {
                ++left;
            } else {
                --right;
            }
        }

        // 返回遍历中记录的最大面积。
        return maxWater;
    }
};
```

**为什么移动较短的一侧？** 当前面积受短板限制。若保留短板、只移动较高的一侧，容器宽度会变小，而高度仍不可能超过原来的短板，面积不会变大。移动短板则可能遇到更高的线，抵消宽度变小带来的损失。

**复杂度：** 时间 `O(n)`，额外空间 `O(1)`。每一步都会让一个指针向内移动，最多扫描数组一次。
