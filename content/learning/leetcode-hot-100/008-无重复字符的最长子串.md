# 008｜无重复字符的最长子串

**LeetCode：** 3　**标签：** `滑动窗口` `Hash`　**难度：** 中等

给定字符串 `s`，返回不包含重复字符的最长子串长度。子串必须连续，不能跳过中间字符。

- `"abcabcbb"` → `3`，如 `"abc"`。
- `"bbbbb"` → `1`。
- `"pwwkew"` → `3`，如 `"wke"`；`"pwke"` 不连续，不是子串。
- 空字符串 → `0`。

## 共同思路：滑动窗口

用左右指针表示一个连续区间，用哈希集合记录窗口内的字符，保持窗口内没有重复字符。左右指针都只向右移动，已扫描过的部分不必从头检查。

集合记录的是**当前窗口内的字符**，不是整个字符串中出现过的字符。窗口左边界右移时，必须把离开窗口的字符从集合中删除。

## 方法一：枚举左边界，尽量扩展右边界

这是截图中的 C++ 写法。每次固定左边界，尽量向右扩展，直到下一个字符已经存在于窗口中；记录长度，再把左边界向右移动一格。

- `right` 初始为 `-1`，表示窗口还没有字符。
- 左边界移到 `left` 时，删除上一轮离开的字符 `s[left - 1]`。
- 只要下一个字符不重复，就把它加入集合并移动 `right`。
- 扩展结束后的窗口是闭区间 `[left, right]`，长度为 `right - left + 1`。

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        // 保存当前窗口中的字符，用于判断重复。
        unordered_set<char> window;
        int n = s.size();

        // 初始窗口为空，右边界尚未进入字符串。
        int right = -1;
        int longest = 0;

        // 依次尝试每个左边界。
        for (int left = 0; left < n; ++left) {
            if (left > 0) {
                // 左边界右移后，删除离开窗口的字符。
                window.erase(s[left - 1]);
            }

            // 下一个字符不重复，就继续扩展窗口。
            while (right + 1 < n && !window.count(s[right + 1])) {
                window.insert(s[right + 1]);
                ++right;
            }

            // 当前窗口是从 left 开始的最长无重复子串。
            longest = max(longest, right - left + 1);
        }

        return longest;
    }
};
```

**为什么右指针不用退回去？** 上一轮窗口内没有重复字符，删除最左边字符后，剩余部分仍然不重复，可以直接尝试继续向右扩展。

### count() 和 ! 的含义

截图中的集合叫 `occ`，本笔记中叫 `window`，作用相同。`occ.count(c)` 返回集合中字符 `c` 的数量。因为 `unordered_set` 不允许重复元素，所以字符存在时返回 `1`，不存在时返回 `0`。

在条件判断中，`0` 表示假，非零表示真；`!` 是逻辑取反：

| 字符是否在集合中 | count() 返回值 | 加 ! 后的结果 |
|---|---:|---|
| 存在 | 1 | false |
| 不存在 | 0 | true |

因此，`!occ.count(s[rk + 1])` 表示“下一个字符不在当前窗口中”，可以继续扩展窗口。它等价于 `occ.count(s[rk + 1]) == 0`。本笔记代码中的 `!window.count(s[right + 1])` 也是这个意思。

**复杂度：** 平均时间 `O(n)`，额外空间 `O(min(n, Σ))`，其中 `Σ` 是字符集大小。左右指针各最多移动 `n` 次；哈希集合操作平均为 `O(1)`。

## 方法二：扩展右边界，遇到重复就缩小窗口

这是截图中 Java 写法对应的 C++ 版本。两种写法都使用滑动窗口，只是外层循环控制的边界不同。这个版本每轮处理一个新字符，步骤更统一：

```text
读取右端新字符 → 若重复则缩小左边界 → 加入新字符 → 更新最长长度
```

### C++ 代码

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        // 保存当前窗口中的字符。
        unordered_set<char> window;
        int left = 0;
        int longest = 0;
        int n = s.size();

        // 每轮尝试把右端的新字符加入窗口。
        for (int right = 0; right < n; ++right) {
            char current = s[right];

            // 新字符已在窗口中，就不断移除左端字符。
            while (window.count(current)) {
                window.erase(s[left]);
                ++left;
            }

            // 原来的重复字符已移出，现在可以加入新字符。
            window.insert(current);

            // 此时 [left, right] 内没有重复字符。
            longest = max(longest, right - left + 1);
        }

        return longest;
    }
};
```

### 为什么用 while，而不是 if？

遇到重复字符时，删除最左边的一个字符不一定能消除重复。例如 `"abba"`：扫描到第二个 `b` 时，窗口是 `"ab"`。先删除 `a`，窗口里还有 `b`，必须继续删除旧的 `b`，才能加入新的 `b`。

`while` 会一直缩小窗口，直到旧的重复字符离开；然后再加入当前字符，保证窗口仍然不重复。

### 手算："abba"

| right | 新字符 | 缩小窗口的操作 | left | 加入后的窗口 | 长度 | 最长长度 |
|---:|---|---|---:|---|---:|---:|
| 0 | a | 无 | 0 | a | 1 | 1 |
| 1 | b | 无 | 0 | ab | 2 | 2 |
| 2 | b | 依次删除 a、旧 b | 2 | b | 1 | 2 |
| 3 | a | 无 | 2 | ba | 2 | 2 |

**复杂度：** 平均时间 `O(n)`，额外空间 `O(min(n, Σ))`。虽然有内层 `while`，每个位置的字符也只会随右边界加入一次、随左边界移除至多一次，总操作次数仍然是线性的。

## 两种写法对照

| 对照项 | 方法一 | 方法二 |
|---|---|---|
| 外层循环 | 每轮移动左边界 | 每轮移动右边界 |
| 遇到重复 | 暂停扩展右边界 | 缩小左边界直到不重复 |
| 加入字符的时机 | 扩展右边界时 | 消除重复之后 |
| 适合记忆的步骤 | 移除旧左端，再尽量扩展 | 扩展、检查、收缩、更新 |

Java 到 C++ 的对应关系：`HashSet<Character>` → `unordered_set<char>`，`contains` → `count`，`remove` → `erase`，`add` → `insert`，`Math.max` → `max`。C++ 的 `string` 可以直接用 `s[i]` 访问字符，无需先转成字符数组。
