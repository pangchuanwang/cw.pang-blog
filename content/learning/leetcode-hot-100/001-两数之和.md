# 001｜两数之和

**标签：** `Hash`　**难度：** 简单

给定整数数组 `nums` 和目标值 `target`，返回两数之和等于 `target` 的两个下标。同一元素不能重复使用。

示例：`nums = [2,7,11,15]`，`target = 9` → `[0,1]`

## 解法一：暴力枚举

枚举每一对不同下标，检查对应数字之和。

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        // 外层循环依次选取第一个数。
        for (int i = 0; i < nums.size(); ++i) {
            // 从 i + 1 开始，避免重复配对或重复使用同一元素。
            for (int j = i + 1; j < nums.size(); ++j) {
                // 找到和为 target 的一对数后，返回它们的下标。
                if (nums[i] + nums[j] == target) {
                    return {i, j};
                }
            }
        }

        // 题目保证有解；此处作为兜底返回。
        return {};
    }
};
```

时间 `O(n²)`，额外空间 `O(1)`。

## 解法二：哈希表

哈希表保存“数值 → 下标”。遍历时先查找补数 `target - nums[i]`，找不到再把当前数存入表中。

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        // 记录已遍历元素：数值 -> 下标。
        unordered_map<int, int> index;

        for (int i = 0; i < nums.size(); ++i) {
            // 计算与当前数相加后等于 target 的补数。
            int need = target - nums[i];

            // 若补数已出现，直接返回补数和当前数的下标。
            if (index.count(need)) {
                return {index[need], i};
            }

            // 补数尚未出现，保存当前数供后续查找。
            index[nums[i]] = i;
        }

        // 题目保证有解；此处作为兜底返回。
        return {};
    }
};
```

### 哈希表复杂度

- **平均时间 `O(n)`**：遍历 `n` 个元素，每次查找和插入平均为 `O(1)`。
- **额外空间 `O(n)`**：哈希表最坏需要保存接近全部元素。
- `unordered_map` 单次操作平均为 `O(1)`；大量哈希冲突时，最坏可能为 `O(n)`，整体最坏时间可能为 `O(n²)`。
