# 010｜和为 K 的子数组

**LeetCode：** 560　**标签：** `前缀和` `Hash`　**难度：** 中等

给定整数数组 `nums` 和整数 `k`，统计和恰好为 `k` 的连续非空子数组个数。

- `nums = [1,1,1]`，`k = 2` → `2`，对应下标区间 `[0,1]` 和 `[1,2]`。
- `nums = [1,2,3]`，`k = 3` → `2`，对应 `[1,2]` 和 `[3]`。

不同下标区间分别计数，即使它们包含的数值相同。

## 方法一：枚举子数组

固定右端点 `right`，从它向左逐步扩展起点 `left`。每次加上一个数，就得到新区间 `[left, right]` 的和，不必重新遍历区间求和。

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        int n = nums.size();
        int count = 0;

        // 依次枚举子数组的右端点。
        for (int right = 0; right < n; ++right) {
            int sum = 0;

            // 从右端点向左扩展，逐步累加区间和。
            for (int left = right; left >= 0; --left) {
                sum += nums[left];

                // 每个符合条件的下标区间分别计数。
                if (sum == k) {
                    ++count;
                }
            }
        }

        return count;
    }
};
```

这里直接读取 `nums`，不需要像截图中那样复制到 `arr`。

**复杂度：** 时间 `O(n²)`，额外空间 `O(1)`。这是用于理解题意的基础解法，大规模输入时应使用方法二。

## 方法二：前缀和 + 哈希表（重点）

### 1. 为什么查找 pre - k？

前缀和是从数组开头累加到某个位置的总和。用当前前缀和减去更早的前缀和，得到中间子数组的和：

```text
当前前缀和 - 更早的前缀和 = k
更早的前缀和 = 当前前缀和 - k
```

所以，遍历到当前元素时，只需要查找之前出现过多少次 `pre - k`。每出现一次，就对应一个以当前位置结尾、和为 k 的子数组。

### 2. 哈希表保存什么？

`frequency` 的键是前缀和，值是这个前缀和此前出现的次数。例如 `frequency[2] = 3`，表示之前有三个前缀的和为 2。

必须保存**次数**，不能只保存是否存在：数组含有 0 或负数，相同前缀和可能出现多次，每一次都对应不同的起点。

### 3. C++ 代码

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        // 前缀和 -> 该前缀和此前出现的次数。
        unordered_map<int, int> frequency;

        // 数组开始前有一个和为 0 的空前缀。
        frequency[0] = 1;

        int pre = 0;
        int count = 0;

        for (int num : nums) {
            // 更新从数组开头到当前位置的前缀和。
            pre += num;

            // 查找能与当前前缀和相减得到 k 的旧前缀和。
            auto it = frequency.find(pre - k);
            if (it != frequency.end()) {
                // 每次旧前缀出现，都对应一个满足条件的子数组。
                count += it->second;
            }

            // 查找完成后，再记录当前前缀和。
            ++frequency[pre];
        }

        return count;
    }
};
```

### 4. 关键语句说明

- `frequency[0] = 1`：记录数组开始前的空前缀。当当前 `pre == k` 时，可以通过 `pre - k == 0`，统计从下标 0 开始的子数组。空前缀只是计算工具，答案仍是非空子数组。
- `find(pre - k)`：查找需要的旧前缀和；没找到时返回 `end()`，找到时 `it->second` 就是出现次数。
- `++frequency[pre]`：当前前缀和的次数加 1。键不存在时，`unordered_map` 的 `[]` 会先创建值为 0 的表项，再加到 1。
- **先查询、后记录**：确保使用的是更早的前缀。如果先记录当前前缀，当 `k == 0` 时，会把当前前缀减自身对应的空区间也算进去。

### 5. 手算：[1,1,1]，k = 2

初始表为 `{0: 1}`，`pre = 0`。

| 下标 | 当前数 | pre | 查找 pre - k | 旧前缀出现次数 | 本轮新增 | 累计答案 |
|---:|---:|---:|---:|---:|---:|---:|
| 0 | 1 | 1 | -1 | 0 | 0 | 0 |
| 1 | 1 | 2 | 0 | 1 | 1 | 1 |
| 2 | 1 | 3 | 1 | 1 | 1 | 2 |

每轮查询后，把当前 `pre` 的次数加 1。最后得到两个子数组 `[0,1]`、`[1,2]`。

再看 `[0,0]`、`k = 0`：第一轮查到一个旧前缀和 0，新增 1；记录后，前缀和 0 出现次数变为 2。第二轮查到两个旧前缀，新增 2，总答案为 3，即两个单独的 `[0]` 和整个 `[0,0]`。

**复杂度：** 平均时间 `O(n)`，额外空间 `O(n)`。每个元素只处理一次，哈希表查找和插入平均为 `O(1)`。

**注意：** 数组允许负数，区间和不会随窗口扩展而单调增加，因此不能直接套用“和大了就缩小、和小了就扩展”的滑动窗口。枚举时也不能因为 `sum > k` 就提前结束。
