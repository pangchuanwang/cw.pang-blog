# 003｜最长连续序列

**标签：** `Hash`　**难度：** 中等

给定未排序整数数组 `nums`，找出数字连续（不要求在原数组中相邻）的最长序列长度。要求时间复杂度为 `O(n)`。

示例：`nums = [100,4,200,1,3,2]` → `4`，最长连续序列是 `[1,2,3,4]`。

## 解法：哈希集合

先把数字放入哈希集合，去重并支持平均 `O(1)` 查找。只从没有前驱 `num - 1` 的数字开始向后查找，避免对同一段连续序列重复计算。

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        // 放入集合：去除重复数字，并支持快速查找。
        unordered_set<int> numSet(nums.begin(), nums.end());

        // 记录目前找到的最长连续序列长度。
        int longestStreak = 0;

        // 遍历集合中的每个不同数字。
        for (int num : numSet) {
            // 有前驱的数字不是序列起点，跳过以免重复扫描。
            if (numSet.count(num - 1)) {
                continue;
            }

            // 当前数字没有前驱，从它开始向后扩展序列。
            int currentNum = num;
            int currentStreak = 1;

            // 只要下一个连续数字存在，就继续扩展并计数。
            while (numSet.count(currentNum + 1)) {
                ++currentNum;
                ++currentStreak;
            }

            // 用当前序列长度更新全局最大值。
            longestStreak = max(longestStreak, currentStreak);
        }

        // 空集合返回 0；否则返回最长连续序列长度。
        return longestStreak;
    }
};
```

**复杂度：** 平均时间 `O(n)`，额外空间 `O(n)`。虽然有内层 `while`，但每个数字只会在所属序列从起点扩展时被访问一次，因此总扩展次数是线性的。
